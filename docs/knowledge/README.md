# Agent knowledge catalog

This library contains reference notes that agents can search and read from a local checkout. Each collection has a topic index, and each note names the official sources used to verify it.

| Collection | Use it for |
| --- | --- |
| [OpenAI agent building](openai/agent-building/README.md) | Choosing a runtime or tool, retrieving evidence, coordinating agents, reviewing actions, and evaluating an answer. |

## Finding an answer

1. Open the collection that matches the question. Its index maps questions to notes.
2. Read the relevant heading and its surrounding passage. For a question that spans topics, follow the links or search the collection for a second passage.
3. Cite the local file and heading that support the answer. If the collection lacks the requested fact, say what is missing. The official links identify where to check when online.

## Adding or refreshing a collection

Give each new topic its own folder and add it to the table above. Use descriptive headings, write the answer in the note, and place the source link beside the passage it supports. When a source changes, update the affected passages, verify their links, and record the date they were checked. Update the topic index when a note moves or its coverage changes.
