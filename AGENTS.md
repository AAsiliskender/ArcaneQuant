# Repository knowledge

The [local knowledge catalog](docs/knowledge/README.md) lists the available topics, starting with OpenAI agent building. When a task matches a topic, follow its index to the relevant passage and cite the file and heading that support your answer.

## Parallel coding agents

When drafting ArcaneQuant agent identities or assignments with `prompt-agent-identity` or `prompt-agent-task`, incorporate the corresponding instructions from [the agent team guide](docs/agents/README.md) in the generated prompt. When running a parallel coding assignment, the orchestrator and workers follow that guide. Allocate folders when an agent receives real work.
